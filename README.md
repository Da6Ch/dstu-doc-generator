# Інтелектуальна система автоматизації формування проектної документації ПЗ

Прототип вебсистеми, що приймає посилання на публічний Git-репозиторій,
виконує текстово-структурний аналіз коду та за допомогою хмарного LLM
(Google Gemini) формує документацію відповідно до ДСТУ/ЄСПД серії 19.

## Архітектурна схема

```
┌──────────────┐   1. URL репозиторію    ┌───────────────────┐
│   Клієнт      │ ──────────────────────▶ │  Next.js фронтенд  │
│ (браузер)     │ ◀────── SSE-потік ────── │  app/generate/page │
└──────────────┘                          └─────────┬──────────┘
                                                      │ POST /api/generate
                                                      ▼
                                        ┌──────────────────────────┐
                                        │   API Route (Node.js)    │
                                        │  app/api/generate/route  │
                                        └─────────┬─────────────────┘
                                                   │
                     ┌─────────────────────────────┼─────────────────────────────┐
                     ▼                             ▼                             ▼
          ┌────────────────────┐      ┌───────────────────────┐      ┌────────────────────┐
          │ 1. cloneRepo()      │      │ 2. collectRepoFiles() │      │ 3. buildRepoDigest()│
          │ isomorphic-git, tmp │ ───▶ │ фільтрація сміття,    │ ───▶ │ дерево + пріоритет- │
          │ shallow clone (fs)  │      │ побудова дерева файлів│      │ ний конспект коду   │
          └────────────────────┘      └───────────────────────┘      └──────────┬──────────┘
                                                                                  ▼
```

## Покроковий опис роботи модулів

1. **`lib/git/cloneRepo.ts`** — за посиланням GitHub клонує репозиторій
   (shallow, depth=1) у тимчасову теку (`os.tmpdir()`) через вбудований `node:fs`;
   тека видаляється одразу після формування конспекту.
2. **`lib/git/filterFiles.ts`** — рекурсивно обходить дерево, виключає
   `node_modules`, `.git`, білд-директорії, lock-файли та бінарні асети;
   формує `RepoTreeNode[]` (для UI) і `RepoFile[]` (текстовий вміст для
   аналізу), зчитує `README.md`.
3. **`lib/git/buildDigest.ts`** — агрегує відфільтровані файли в один
   пріоритезований текстовий блок («конспект коду») з обмеженням розміру
   під контекстне вікно моделі.
4. **`lib/llm/prompts/*.ts`** — окремий шаблон промпту під кожен стандарт
   (19.201, 19.402, 19.404, 19.505) з жорсткою структурою розділів.
5. **`lib/llm/geminiClient.ts`** — обгортка над `@google/genai`, що виконує
   `generateContentStream` і повертає фрагменти тексту через callback.
6. **`app/api/generate/route.ts`** — оркеструє весь пайплайн і транслює
   прогрес (`status`, `tree`, `doc-start`, `doc-chunk`, `doc-end`, `done`,
   `error`) клієнту через Server-Sent Events.
7. **`app/generate/page.tsx`** — клієнтський стрім-рідер: читає SSE
   вручну через `fetch().body.getReader()` (замість `EventSource`, який не
   підтримує POST-запити), оновлює UI посимвольно в реальному часі.
8. **`components/DocumentReader.tsx`** — рендерить Markdown з підтримкою
   GFM-таблиць і діаграм Mermaid.js; кнопки експорту в `.md` та `.docx`.

## Запуск прототипу

```bash
npm install
cp .env.example .env.local   # (Windows: copy .env.example .env.local) і вставити GEMINI_API_KEY
npm run dev
```

Відкрити `http://localhost:3000`, вставити посилання на публічний
репозиторій, обрати потрібні артефакти ДСТУ та натиснути «Згенерувати
документацію».

## Можливі напрями розвитку для магістерської роботи

- Заміна shallow-clone на GitHub REST API (Contents API) для
  роботи без повного клонування — швидше для великих репозиторіїв.
- Кешування дайджестів репозиторію (за SHA останнього коміту) для
  повторної генерації без повторного аналізу.
- Порівняльний розділ у пояснювальній записці — оцінка якості згенерованої
  документації (BLEU/ROUGE до еталонних документів або експертна оцінка).
- Підтримка кількох LLM-провайдерів (OpenAI-сумісний інтерфейс уже
  закладений у вибір `@google/genai`) для порівняльного аналізу якості.
